# 💤 LazyVim

My customized version of LazyVim

## Installation (Linux)

```
```bash
  cd ~/.config
  rm -rf nvim
  git clone https://github.com/sk1ll1ssu3/nvim
```

You can also run this command to remove the git folder and make it your
own repo later

```bash
  cd ~/.config/nvim/
  git pull
```
```
## Update

You don't need to run this if this is your own repo now

```bash
  cd ~/.config/nvim/
  git pull
```
